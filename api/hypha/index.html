hypha — the node host binary. hypha serve runs the substrate daemon with zero integration kinds; integrations ship their own binaries that compose hypha_node::serve_state with their planes.

Env: HYPHA_HOST/HYPHA_PORT (or PORT), HYPHA_TOKEN (required on non-loopback binds), HYPHA_HOME, HYPHA_NODE, HYPHA_NAME, HYPHA_ORIGINS, HYPHA_SSE_KEEPALIVE_MS, HYPHA_PAIR_LIMIT_*, HYPHA_PUSH/HYPHA_PUSH_PATH, and the OTEL vars (HYPHA_OTEL_*/OTEL_EXPORTER_OTLP_*).
