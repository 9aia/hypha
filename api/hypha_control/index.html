hypha-control — the policy layer over entity planes: who may hold an entity (lock registry), when a takeover preempts (arbitration), which node owns an entity (routing), and how multi-node indexes merge. Mechanism stays with integrations (sepia drives sessions) — hypha decides, the integration executes.

Every type here is pure — no I/O — so policy is testable without standing up nodes. Wire calls (sepia serve//api/*) happen in hypha-node, which consult this crate for the decisions.
