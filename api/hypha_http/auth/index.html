Module auth

Bearer auth — port of peregrin’s app.ts isAuthorized/ unauthorizedResponse plus the login/logout cookie exchange and POST /api/pair code redemption. Substrate routes only: the per-session SSE ?access_token path is the integration’s to add (see [is_query_token_path]).

Constants§

AUTH_COOKIE
Cookie name — value is the credential itself (env token or paired).

Functions§

accepts_credential
Whether the presented credential authenticates — env token or an issued pair credential (checked by hash: equivalent privilege, but revocable-by-file-deletion and never stored in plaintext).
auth_gate
The bearer gate — middleware mounted over the whole app; pre-auth routes and non-/api paths pass through (the gate applies only when the first segment is api).
handle
POST /api/auth/login — exchange a presented token for an httpOnly cookie; POST /api/auth/logout — expire it.
pair
POST /api/pair — pairing: deliberately unauthenticated — the code, not a bearer token, authorizes it. Per-IP throttled: every POST counts, malformed bodies included.
