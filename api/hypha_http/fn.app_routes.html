pub fn app_routes(state: &HyphaState) -> Router<HyphaState>
Expand description

Build the substrate route table + middleware WITHOUT the terminal fallback — returns Router<HyphaState> so an integration can .with_state(...) it and merge it with its own router under one listener. axum panics merging two routers that both carry a custom fallback, so the composer installs exactly one (see app_routes vs app).

Only the kind-agnostic surface: health, pairing + auth bootstrap, node, fs, user, the event feed, /api/entities* plus the /api/entity-index//api/pending-ops reads, and /api/push/*. Every route is any() + an internal method guard so wrong-method requests fall through to the 404 (rather than axum’s bare 405). Integrations nest their own routes around or inside this router and register entity planes on the shared HyphaState.
