Module entities

Expand description

The entity surface — /api/entities* is the substrate-facing view of everything a node hosts. Every handler here is kind-agnostic: it parses just enough of the request to pick a plane out of the EntityContext::kinds registry (body.kind, the <ns>.<verb> op namespace, or owner-resolution across planes for id-scoped calls) and hands over verbatim — payload translation, status codes, and feed emission stay inside each kind’s EntityPlane impl.

Integrations register planes at composition (crate::HyphaState::with_kind). entity.* is the substrate’s own op namespace: entity.delete resolves the owning plane and deletes through it.

Handlers extract HyphaState only to build the EntityContext — the entity-plane contract itself sees nothing else.

collection
GET /api/entities[?kind=][&withLocks=1] — every registered plane’s entity docs (or just one kind’s when ?kind= filters); POST /api/entities — {kind?, indexDoc} → the kind’s create.
entity_index
GET /api/entity-index — the single-node entity index: this node’s id plus every registered plane’s entity docs (?kind= filters, same as GET /api/entities). The hub’s merged multi-node version is hypha-hub’s entity_routes::entity_index; both answer {"index": [{node, entities}]}.
item
GET /api/entities/{id} — the owning plane’s entity doc (first non-404 wins; all-404 answers the last one). DELETE is entity.delete.
ops
POST /api/entities/{id}/ops — submit {kind, payload}. entity.delete (and the bare delete alias) is substrate-generic; <ns>.<verb> dispatches to the plane owning ns; bare verbs fall back to the default plane — legacy un-namespaced outbox rows.
pending_ops
GET /api/pending-ops — the node’s outbox view. A bare node owns no outbox (the durable queue lives hub-side in hypha-hub), so the honest answer is an empty list — same {"ops": [...]} shape the hub serves.
snapshot_collection
POST /api/entities/snapshot — import a snapshot on this node; body.kind picks the plane (absent → the default plane).
snapshot_item
GET /api/entities/{id}/snapshot — kind-shaped snapshot bytes the substrate moves opaquely; the owning plane produces them.
