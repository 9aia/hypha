Route helpers — the substrate half of peregrin’s routes/shared.ts: the {error} body shape, JSON-body reading with per-route caps, and query-param decoding. Session-shaped wire types and the ControlError → status mapping stay with the integration that owns them.

Modules§

entities
The entity surface — /api/entities* is the substrate-facing view of everything a node hosts. Every handler here is kind-agnostic: it parses just enough of the request to pick a plane out of the EntityContext::kinds registry (body.kind, the <ns>.<verb> op namespace, or owner-resolution across planes for id-scoped calls) and hands over verbatim — payload translation, status codes, and feed emission stay inside each kind’s EntityPlane impl.
events
GET /api/events — the substrate event feed (the routes/events.ts shape): each connection drains a bounded subscription; a client that stops draining is terminated rather than wedging the feed. Heartbeats ride the stream as real heartbeat events, not comment pings. Event kinds are whatever the registered integrations emit — the route is kind-agnostic.
misc
routes/misc.ts + routes/fs.ts + routes/node.ts substrate halves — health probe, directory listing for pickers, node descriptor, user info. Session-shaped handlers (the session-list health probe, meta-backed config/projects) stay with the integration.
push
Push subscription management — authenticated like every other /api route: an open subscribe endpoint would let anyone on the network register their own endpoint and receive notification payloads. Backed by hypha_push::PushStore; None on the state answers 501.

Hard ceiling — POST /api/entities/snapshot carries a whole exported snapshot; nothing else legitimately approaches this.
SMALL_JSON_BODY
Small bodies — pair codes, login tokens, renames, op submissions, push subscriptions. The biggest legit field anywhere on these routes is small; 64KiB is generous.
