routes/misc.ts + routes/fs.ts + routes/node.ts substrate halves — health probe, directory listing for pickers, node descriptor, user info. Session-shaped handlers (the session-list health probe, meta-backed config/projects) stay with the integration.

Functions§

fs
GET /api/fs?path=/abs/dir — direct children of a directory, for pickers. Directories only, capped at 200.
health
GET /api/health — deliberately ahead of the auth gate (probes). The substrate has no session store to probe; liveness is the answer. Integrations with a deeper health check override by nesting their own route ahead of this router.
node
GET|PATCH /api/node — the node descriptor every federated client hits first; PATCH renames the node and persists the identity file. agents is whatever the composing integration advertises (HyphaState::node_agents — empty on a bare substrate); the substrate’s own capabilities are entities/events/export, plus push/pairing when those backends are wired.
user
GET /api/user — the OS user the node runs as (os.userInfo()).
