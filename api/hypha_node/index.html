hypha-node — the node host library: the thin composition layer between hypha_http::Env and the substrate axum app.

A bare hypha serve mounts zero entity kinds — the substrate surface (/api/health, /api/node, /api/events, /api/pair, /api/auth/*, /api/user, /api/fs, /api/push/*, /api/entity-index, /api/pending-ops, and the entity.* ops namespace) still works end-to-end. Integrations (peregrin’s session plane, campaign planes, …) compose state themselves: build a HyphaState, register their [EntityPlane]s via HyphaState::with_kind, and hand it to serve_state.

Functions§

serve
Build state from env and serve until shutdown — the whole hypha serve boot path. Call on a tokio runtime; returns when the listener fails or after graceful shutdown (SIGINT/SIGTERM).
serve_state
Serve a pre-composed HyphaState — the integration entry point. Same bind + graceful-shutdown contract as serve.
state
The HyphaState a bare node serves — HyphaState::from_env with no kind planes registered. Integrations wanting planes call HyphaState::from_env(env) directly and .with_kind(...).
