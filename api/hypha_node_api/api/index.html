The EntityApi port — the node daemon’s entity-plane surface — plus HttpEntityApi, the ureq-backed client impl. hypha-node’s SyncEntityApi is the sync-engine impl; integrations and clients call through whichever Arc<dyn EntityApi> the host provides.

HttpEntityApi
EntityApi backed by the node daemon’s HTTP API (ureq — blocking I/O, so each trait method hops onto spawn_blocking).

Traits§

EntityApi
Port to the node’s entity plane — implemented by HttpEntityApi for direct connections and by the hub’s SyncEntityApi (merged index + durable outbox) for multi-node deployments. Deliberately kind-agnostic: Op.kind and EntityDto.index_doc are owned by the integration, never by this crate (ADR-0091).
