Expand description

Port to the node’s entity plane — implemented by HttpEntityApi for direct connections and by the hub’s SyncEntityApi (merged index + durable outbox) for multi-node deployments. Deliberately kind-agnostic: Op.kind and EntityDto.index_doc are owned by the integration, never by this crate (ADR-0091).
