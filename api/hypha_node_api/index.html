hypha-node-api — the node daemon’s entity-plane surface as a Rust port, shared by hypha-node (its SyncEntityApi impl) and integrations/clients. Pure Rust — no leptos, no DOM, and deliberately kind-agnostic: entity kinds, op kinds, and index_doc/payload shapes belong to integrations (sepia-peregrin), never to this crate (ADR-0091).

Modules§

api
The EntityApi port — the node daemon’s entity-plane surface — plus HttpEntityApi, the ureq-backed client impl. hypha-node’s SyncEntityApi is the sync-engine impl; integrations and clients call through whichever Arc<dyn EntityApi> the host provides.
dto
Wire DTOs for the entity plane — kind-agnostic by design (ADR-0091). index_doc/payload are opaque JSON to hypha: the integration (e.g. sepia-peregrin) defines what they hold for its entity kind. Tolerant decode everywhere (#[serde(default)], Value for blobs).
testing
Test fixtures — a deterministic in-memory EntityApi. FakeEntityApi::seeded() returns a fixed world (three entities across two kinds, a node descriptor, an empty outbox); .with_* knobs override individual fixtures and .with_error(..) makes every read endpoint fail.
