hypha-outbox — durable queued writes for offline nodes.

When a target node is unreachable the hub appends the intended write (any entity op…) here instead of dropping it. Entries drain in per-entity FIFO order once the node is reachable again; entries that exhaust their retry budget or TTL move to dead-letter rather than disappearing.

Ordering guarantee: per (node_id, entity_id) the queue is FIFO. Metadata ops (rename, pin) are safe under last-writer-wins replay; turn-shaped ops (opaque verb kinds — the caller decides) dead-letter on failure rather than interleave with newer writes — the caller decides.
