NodeClient — the hub→node HTTP client (entity plane, ADR-0091).

Blocking on purpose (ureq): the sync engine runs it on spawn_blocking threads. Carries a per-node bearer token, reads the entity index as raw Value docs (the projection stores them verbatim), posts entity-scoped ops, and tails /api/events as a data: {json} SSE line reader.

INTERIM: today’s nodes still expose the session plane — this client reads /api/entities* docs natively and routes sepia.<verb> ops onto session endpoints. When the node grows the integration-backed /api/entities surface (phase 4), this module shrinks to the generic contract.
