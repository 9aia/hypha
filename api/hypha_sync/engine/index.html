hypha_sync

Module engine 

Source
Expand description

The sync engine — one supervised loop per node, JoinSet-managed, CancellationToken-cancellable.

Per node the cycle is: list_entities → upsert + reconcile the projection → drain the outbox FIFO → tail /api/events and apply index diffs → on stream end/error, mark the node down and reconnect with capped exponential backoff + jitter. A periodic full-list reconcile catches anything the feed missed (tombstones are only visible in listings).
