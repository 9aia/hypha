pub async fn add_node(&self, target: NodeTarget) -> Result<(), SyncError>

Register a node and start syncing it. Re-registering an existing id retargets the node — the running loop is aborted and respawned with the new target (e.g. a credential minted after boot); the projection’s node row + session index survive the swap.

§Errors

SyncError::Shutdown if the engine is gone; sqlite failure writing the node row.

Source

pub async fn remove_node(&self, id: &str) -> Result<(), SyncError>

Stop syncing a node and drop its projected state.

§Errors

SyncError::Shutdown if the engine is gone; sqlite failure.

Source

pub async fn submit_op( &self, write: NodeWrite, ) -> Result<SubmitOutcome, SyncError>

A write to a node: posted immediately when the node is up; appended to the durable outbox (per-entity FIFO) when it’s down or the direct post fails on transport. HTTP rejections surface as errors — they were delivered and refused, not lost.

§Errors

SyncError::UnknownNode for unregistered ids, SyncError::Node when the node rejects the write, and outbox/sqlite failures.

Source

pub async fn shutdown(self)

Stop every loop and await the supervisor. The SSE pump threads exit at the next feed frame or the sse_idle_timeout read deadline — Self::active_pumps reports stragglers.
