hypha-sync — the hub-side sync layer (entity plane, ADR-0091).

Keeps a local SQLite projection (ProjectionStore) of every paired node’s entity index: index_doc rows only — opaque integration docs — never detail payloads (those stay node-fetched). The SyncEngine runs one supervised loop per node: connect → list_entities → drain the durable Outbox → tail /api/events for index diffs → reconnect with capped exponential backoff + jitter.

Writes while a node is down go through SyncHandle::submit_op, which posts directly when the node is up and enqueues into hypha-outbox otherwise.
