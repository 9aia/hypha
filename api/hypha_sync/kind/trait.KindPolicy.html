Expand description

One entity kind’s sync-side policy. All methods have inert defaults — a minimal policy is entity_kinds plus whatever the kind actually needs.

Required Methods§

Source

fn entity_kinds(&self) -> &'static [&'static str]

Entity kind tags this policy serves ("sepia-session", "campaign", …). A kind is “registered” for create/gating purposes iff some policy claims it.

Provided Methods§

Source

fn diff_events(&self) -> &'static [&'static str]

SSE event: names whose {id, patch} frames are this kind’s index diffs. Empty = the kind only syncs via full listings.

Source

fn tombstone(&self, _event: &str) -> DiffTombstone

Tombstone resolution for one of Self::diff_events.

Source

fn owns_op(&self, _op: &str) -> bool

Does this policy arbitrate op (<ns>.<verb>)? First registered claimant wins — keep namespaces disjoint.

Source

fn op_gated(&self, _op: &str) -> bool

Does op contend for the entity’s live lock (gated writes consult the hub’s lock book before queueing/posting)? Only consulted for ops Self::owns_op claims; entity.delete is substrate-gated regardless.

Source

fn op_kind(&self, _op: &str) -> OpKind

Outbox replay classification for an owned op — OpKind::Metadata retries, OpKind::Turn dead-letters. Only consulted for ops Self::owns_op claims.

Source

fn call_params(&self, _scope: Option<&str>) -> Vec<(String, String)>

Query params appended to entity-scoped node calls (GET /api/entities/{id}, POST …/ops, stream opens). scope is the caller’s hint — today the entity kind value itself, forwarded verbatim (the interim disambiguator).

Source

fn stream_path(&self, _id: &str) -> Option<String>

Live event-stream path for the entity — id is already percent-encoded. None = the kind has no entity stream.

Source

fn external_actor_id(&self, _row: &IndexedEntity) -> Option<String>

The holder id recorded for a locked projection row the hub never granted — None reads as "external". Only consulted for rows whose kind this policy serves.

Source

fn columns(&self, _raw: &Value) -> Option<IndexColumns>

Column extraction override for this kind’s wire docs — merged over the generic rules field-by-field. None = generic.

Source

fn create_kind(&self, requested: &str) -> Option<&'static str>

The canonical entity kind a create request for requested maps to — None = this policy doesn’t serve the create. Default: the kind itself when it’s one of Self::entity_kinds; integrations override to accept aliases ("session" → "sepia-session").

Source

fn validate_create(&self, _init: &Value) -> Result<(), String>

Create-payload validation — runs after Self::create_kind accepts the kind. Err rejects the create before it posts.

Source

fn notices( &self, _event: &str, _entity_id: &str, _row: Option<&IndexedEntity>, _patch: &Value, ) -> Vec<Notice>

User-facing notices this kind wants delivered for a diff event on entity_id. row is the projected entity when indexed (None — e.g. a diff ahead of the first listing — implementations fall back to the id). Default: none.
