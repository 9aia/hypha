Struct ProjectionStore 

Source 
pub struct ProjectionStore { /* private fields */ }
Expand description

The local projection — a materialized view of every paired node’s entity index plus per-node liveness and resync cursors. Clone shares one connection (same pattern as hypha-outbox).

pub fn purge_unregistered(&self, keep: &[String]) -> Result<(), SyncError>

Drop every row belonging to a node id that’s no longer registered — a renamed id (node→main), a node removed from PEREGRIN_NODES, or the single-node shorthand id replaced by a real one. Their entity rows have no sync loop anymore and would serve dead entities forever (click → “node not found”). The store is a cache — a still-configured node resyncs itself.
