hypha-systemd — the systemd impl of the hypha-service port: per-user units at ~/.config/systemd/user (no root needed; EnvironmentFile keeps secrets out of the unit). Used by the P6 ops verbs — peregrin create --template writes a unit without enabling it (the operator’s peregrin service enable is the separate step), peregrin destroy service disables + removes it.

systemctl resolves via PATH and every control call is separate from the filesystem ops, so tests can point unit_dir at a tempdir and drive the write/remove paths without touching the user bus (mirroring bupha-systemd’s SystemdService shape).
