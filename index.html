Architecture

Entities

{id, kind, indexDoc, health} — any workload registers a kind; the substrate never names it.

Ops & snapshots

Namespaced ops routed to the owner node; opaque snapshots serialize, transfer, and resume anywhere.

Arbitration

Lock registry, takeover policy, merge/route — who may drive entity X on node Y.

Hub

hypha is the org's distributed substrate — entities, ops, snapshots, locks, and projections that let workloads span machines. It owns the connective layer between nodes and workloads and nothing else: session mechanism is sepia's, orchestration policy is peregrin's, distribution is tamias's.

  • Do a task → How-to — run a node+hub, build and test, read the ledger
  • Understand why → Architecture, concepts, decisions, boundary
  • Look something up → CLI, crates, environment, wire API
