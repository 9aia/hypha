Crates ​

Rust workspace, ports-and-adapters. Lints are strict (pedantic warn, unwrap_used/expect_used warn, unsafe_code forbid); edition 2024, rust-version 1.85.

cratelayerpurpose
hypha-controldomainArbitration — lock registry, takeover policy, merge/route
hypha-kvportNode-local key/value store port — namespaced JSON values with per-namespace visibility (P-006)
hypha-node-apiportNode API port + wire DTOs — the hub/client ↔ node contract. NodeApi trait, ureq client, FakeNodeApi stub, rewind selector, convert targets. No leptos, no DOM.
hypha-secretportSecret-store port
hypha-serviceportService-install port
hypha-dotenvadapterdotenv-file impl of the secret port
hypha-httpadapterHypha HTTP substrate — axum adapter serving /api/entities*, /api/events, node/pairing/auth, and push over a HyphaState
hypha-keyringadapterOS-keyring impl of the secret port
hypha-kv-fileadapterJSON-file impl of the hypha-kv store port — atomic tmp+rename writes (P-006)
hypha-secret-cuoraadapterCuora Secrets impl — resolves cuora://&lt;scope&gt;/&lt;NAME&gt; through the cuora CLI or cuora serve
hypha-systemdadaptersystemd impl of the service port
hypha-telemetryadapterOpt-in OpenTelemetry layer over the tracing stack — OTLP export, W3C context propagation
hypha-outboxserviceDurable per-entity FIFO outbox for writes queued while a node is offline
hypha-pushserviceWeb Push notifications over a JSON document store — VAPID keys persist in config; subscriptions prune on 404/410
hypha-syncserviceHub-side sync layer — SQLite projection of paired nodes' entity indexes + outbox drain on reconnect
hypha-hubengineEntity-API gateway — multi-node sync engine, HTTP/SSE bridges, push, auth
hypha-nodeengineNode host — HyphaState composition + serve() for the substrate daemon
hypha-serve-cliengineOne-shot argv→op-params shim for ndjson *-serve binaries — the generic CLI front door (P-020).
xtasktoolinghypha-xtask — workspace automation.

Migration state lives in org-ledger plan PL-005; crate-level API docs build via bun run docs:api (cargo doc → public/api/).
